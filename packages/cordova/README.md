# @padloc/cordova

> **Deprecated:** Mobile builds now use [@padloc/tauri](../tauri/README.md).
> This package is retained for reference and migration work. Its CI build and

## Requirements (Android)

-   Java (1.8+) or OpenJDK (11+)
-   Android Studio, with:
    -   Android API 30
    -   Android SDK Build tools 30
    -   Android SDK CLI Tools
-   Gradle (7.2, specifically)
